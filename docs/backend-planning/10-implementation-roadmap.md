# Proposed Roadmap

0. Repository and requirements analysis — current phase; stop for approval.
1. Laravel foundation, environments, auth and policies.
2. Buyers/KYC/catalog/pricing.
3. RFQ/quotation/direct buy/PO.
4. Inventory/warehouse/finance.
5. Shipment/reporting/commission/audit/notifications.
6. React API migration module by module.
7. Security, concurrency, performance and quality gate.
8. Deployment/backup/monitoring runbooks.
9. Final acceptance and migration sign-off.

Each phase needs explicit approval, tests and a rollback plan before the next phase.
